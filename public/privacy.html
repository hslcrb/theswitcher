1. 선택한 폰트와 결과

변환은 사용자의 브라우저에서만 실행합니다. 정적 웹페이지는 계정, 업로드 API, 파일 처리 서버를 두지 않으며, 원본·결과·파일 이름·선택한 폴더를 전송하지 않습니다. 선택한 파일과 결과, 오류 기록은 변환 중 페이지 메모리에만 남습니다. 목록을 제거하거나 페이지를 닫으면 앱이 보유한 참조를 해제합니다. 직접 다운로드하거나 폴더에 저장한 사본은 사용자가 관리합니다.

2. 설정 쿠키

jjondeukCookie는 브라우저 기본 다운로드 사용 여부와 완료 파일 기본 선택 여부를 기억합니다. 식별자, 폴더 이름·경로·권한 핸들, 원본 파일, 오류 로그는 쿠키에 넣지 않습니다. 만료는 마지막 설정 변경 후 최대 90일이며, SameSite=Strict를 사용하고 HTTPS에서 Secure를 붙입니다. 쿠키는 같은 사이트의 HTTP 요청에 포함될 수 있지만 앱은 서버에서 쿠키를 읽거나 사용자별로 분석하지 않습니다. 브라우저에서 사이트 데이터를 지우거나 쿠키를 차단해도 변환은 이용할 수 있습니다.

3. 별도 저장 폴더

본인이 별도 저장을 선택한 경우 지원 브라우저가 디렉터리 접근 권한을 확인합니다. 권한은 사용자가 브라우저에서 관리할 수 있습니다. 앱은 폴더 핸들을 페이지 밖에 저장하지 않으므로 페이지를 다시 열면 폴더를 다시 골라야 합니다.

4. 정적 호스팅과 외부 링크

정적 자산을 전송하는 Cloudflare Pages는 제공·보안 목적으로 IP 주소, 요청 정보 등 연결 메타데이터를 처리할 수 있습니다. 이 앱은 별도의 분석·광고 스크립트나 변환용 API를 두지 않습니다. 호스팅 제공자의 처리와 보유는 Cloudflare 개인정보 정책을 참고하세요. GitHub 링크에 들어가면 해당 서비스의 별도 정책이 적용됩니다.

5. 문의와 변경

브라우저에서 설정 쿠키와 파일을 제거할 수 있습니다. 문의는 프로젝트 문의 채널에서 비공개 연락 방법을 요청해 주세요. 공개 이슈에는 연락처, 개인 파일, 오류 원본 또는 식별 가능한 정보를 올리지 마세요. 실질적인 변경은 이 페이지의 시행일 및 저장소 개발기에 기록합니다.
