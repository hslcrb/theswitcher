# 저부하·성능 보강 기록

## 빠른 모드와 압축 모드

첫 구현에서는 모든 WOFF2 인코딩이 레퍼런스 WASM의 높은 압축률 경로를 탔다. 편집 중 반복 변환에는 압축률의 이득보다 대기 시간이 더 컸다. 이제 평소에는 **빠른 변환**, 전송량이 더 중요한 상황에서는 **더 작게**를 선택한다.

| 동일 입력, Node 24.22.3 | 레퍼런스 중앙값 | 빠른 모드 중앙값 | 결과 바이트 (레퍼런스 → 빠른) |
|---|---:|---:|---:|
| Noto Sans Regular, TTF 512,672 B | 1,181.0 ms | 70.9 ms | 179,348 → 226,248 |
| Latin Modern Sans Bold, CFF OTF 107,448 B | 344.7 ms | 8.6 ms | 46,656 → 52,192 |

입력마다 후보를 한 번씩 예열한 뒤 순서를 교대하면서 각 5회 실행했다. 위 수치는 순수 실행 시간이며 모바일 기기·전체 브라우저 로딩 개선 배수로 해석하지 않는다. 빠른 모드는 각각 약 16.7배, 40.2배 빠른 대신 결과가 약 26.1%, 11.9% 커졌다. 정적 첫 화면은 앱 JS 약 7.1 kB, 공유 모듈 약 0.9 kB, CSS 약 3.0 kB를 로드한다(원본 크기). 기본 WOFF2 경로는 약 61 kB 모듈을 지연 로딩하며, 기존 기본 경로의 약 1.02 MB 모듈은 압축 모드에서만 로드한다.

## 기술 결정과 실패 사례

- 처음 검토한 타사 WOFF2 인코더 출력은 사용 중인 레퍼런스 디코더로 돌아오지 않아 채택하지 않았다. 잠금 파일에도 남기지 않았다.
- 선택한 빠른 경로는 원래 테이블을 변경하지 않고 무변환 WOFF2 디렉터리와 스트리밍 Brotli를 조합한다. 압축되는 단위 사이에 원본 전체를 또 복사하지 않는다. 공개 참조 태그 표를 사용하고 디렉터리와 압축 스트림의 길이를 검증한다. 입력 머리글과 출력 컨테이너를 바르게 구분한다.
- Emscripten의 동적 함수 예외는 변환 워커 중 호환 경로에만 남겼다. HTML과 기본 워커에는 없다. 기본 인코더가 예외 워커를 가져오지 않는지 Chromium에서 확인했다. 안정 이름의 파일은 매번 재검증을 요구하고, 해시가 있는 청크만 장기 캐시한다.
- `head` 고정 필드와 보조 블록 경계를 검사한다. 손상된 헤더·구간을 묵인하지 않는다. 동일 컨테이너를 다시 내려받는 경우에는 원본 파일 객체를 재사용하여 불필요한 Blob 복사를 피한다.
- 마지막 UI에서는 배너·일러스트·홍보 문구를 삭제했다. 검정과 흰색, 초록 한 색으로 파일 선택·형식·진행·중지·다운로드를 보여준다.

## 호환성 검증

정적 TTF와 CFF OTF 각각에서 빠른/압축 WOFF2를 Google 기반 디코더로 복원해 원본의 글자 매핑, 이름, 메트릭과 존재하는 지정 테이블을 대조했다. Chromium에서는 기본 변환 결과를 `FontFace.load()`로 읽고, 숨겨진 외부 네트워크 요청 없이 다운로드·취소·재시작이 되는지 확인했다. 테스트 뷰포트는 390px/1280px이며, 실물 저사양 기기 속도나 Safari·Firefox 전수 검증과는 다르다.

| 한국어 가변 테스트 글꼴 | 구조 | 확인한 가변 무게 | cmap / 무게당 advance |
|---|---|---|---:|
| [Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr) 검증용 부분집합 | TrueType 가변 | 100, 500, 900 | 24 / 21 |
| [Adobe Source Han Sans KR 2.005R](https://github.com/adobe-fonts/source-han-sans/releases/tag/2.005R) 검증용 부분집합 | CFF2 가변 | 250, 575, 900 | 24 / 21 |

한글·자모·한자와 영문·숫자를 넣은 작은 테스트 파일을 로컬에서 만들었다. 기본 무게가 최소값과 같은 경우 중간 무게를 추가했다. FontTools로 전체 문자 매핑, 축의 최소/기본/최대값, 대표 글리프의 advance를 두 모드 각각 원본과 대조했다. 이 결과는 전체 글꼴 파일의 모든 글리프와 힌팅이 바이트 동일하다는 의미가 아니다. 시험용 폰트를 저장소나 사이트에 재배포하지 않았다.

```sh
node scripts/benchmark-woff2.mjs /path/to/font.ttf /path/to/font.otf
node scripts/variable-round-trip.mjs /path/to/variable-font.ttf /tmp/qa
python test/variable_semantics.py /path/to/variable-font.ttf /tmp/qa-woff2.sfnt /tmp/qa-woff2-compact.sfnt
```
